BATTERY TESTING PROCEDURE
1. VISUAL INSPECTION:
   Check for: cracked casing, terminal corrosion, electrolyte leaks, bulging (internal pressure), discolouration.
   Clean terminals with sodium bicarbonate solution (neutralises acid). Apply petroleum jelly after cleaning.

2. ELECTROLYTE LEVEL (Lead-Acid only):
   Electrolyte must cover plates by 10-15mm. Add DISTILLED WATER only — never tap water (minerals contaminate). Never add acid unless electrolyte spilled.

3. SPECIFIC GRAVITY (Lead-Acid):
   Use hydrometer. Draw sample from each cell.
   Fully charged: SG = 1.280-1.300 (varies by manufacturer).
   Half charged: SG approximately 1.200.
   Fully discharged: SG approximately 1.100-1.120.
   All cells should have similar SG — variation >0.050 between cells indicates fault.

4. VOLTAGE UNDER LOAD (Load Test):
   Apply rated discharge current (C10 rate — full capacity in 10 hours).
   Monitor terminal voltage — should not drop below 1.75V per cell (lead-acid) or 1.0V per cell (Ni-Cd) within rated capacity time.
   Rapid voltage drop = cell failure or capacity loss.

5. CAPACITY TEST:
   Fully charge battery. Discharge at C10 rate to cutoff voltage. Measure actual Ah delivered.
   If actual Ah < 80% of rated Ah: battery should be replaced.
   GMDSS battery: replace when capacity < 80% rated.
