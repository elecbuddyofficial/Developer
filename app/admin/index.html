Coupons

Comp codes for friends, family, and reviewers. A user redeems one in the app instead of paying.

New Coupon
Codes are case-insensitive and stored uppercase. A buyer types one into "Have a code?" in the upgrade window.
Leave on "Any" unless the offer is meant for one tier. Stops a code aimed at the 12-month plan being spent on the cheapest one.
Which section the offer covers. "Any" lets the buyer choose.
Blocks the code on anything cheaper. Mainly useful with a fixed ₹ discount, so ₹200 off cannot be spent on a ₹299 plan.
How many people in total can use it. 1 for a single person, 50 for a "first 50" campaign. One use per account either way, so nobody can spend it twice.
Last day the code works. Leave blank and it runs until you disable it.
Existing Coupons
Used counts people who have actually spent the code plus anyone part-way through paying with it right now. held is a checkout in progress: it frees itself within 30 minutes if they never pay. refunded means the slot went back to the pool, though that buyer cannot use the code again. over-redeemed means a payment landed after the limit was reached; the money was taken so it was honoured, and it is shown here rather than hidden.
